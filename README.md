# Zen Skills

A collection of focused, production-ready skills for Claude Code and OpenAI Codex.

## Included Skill

### zen-of-search

Route and combine **Anysearch**, **Exa**, **Firecrawl**, and **Tavily** for external information work.

- Current facts, news, and structured verticals
- Scientific and academic research
- Market and competitor research
- GitHub and project research
- Deep multi-source synthesis

Pick the smallest useful provider set, verify claims against original sources, and conserve quota.

claude plugin marketplace add Ttungx/Zen-skills
